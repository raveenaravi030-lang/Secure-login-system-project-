🔒 Secure Login System

Cyber security project · all-in-one HTML file

Security features in this app
  • PBKDF2-SHA256 (310k iterations) with unique salt per user
  • Constant-time comparison of hashes and 2FA codes
  • Strong password policy and common-password blocklist
  • Lockout after 5 failed attempts (5 minutes)
  • Same error for unknown user and wrong password
  • TOTP two-factor authentication (RFC 6238)
  • Hashed session tokens that expire after 15 minutes
  • Audit log of security events
  • Output escaping and strict Content-Security-Policy
